Independent software studio with distinct product identities and a shared design language. Two product families: inclusive learning/accessibility (BrainyTiles, BrainyTalk, Spectrum Explorer, BrainyRoutine) and personal computing/entertainment (ReyOS, Reyva, ReyBeat). ## Shared design system
Consistent typography, spacing, rounded surfaces, icon conventions, contrast, responsive navigation, reduced motion, accessible focus and touch targets. Distinct accents: BrainyTiles violet, BrainyTalk teal, Spectrum Explorer blue/teal, ReyOS copper, Reyva/ReyBeat existing identity. Preserve real logos and existing user theme choices. Do not force identical layouts across desktop, mobile and web. Reuse design tokens conceptually across SwiftUI, React Native and Qt/QML rather than forcing shared runtime.
## Product boundaries
BrainyTiles native SwiftUI iPhone/iPad: preserve all released activities, paid access, bilingual content, adaptive learning, achievements and progress; add accessible modern interface, local multiple profiles and PencilKit where appropriate; keep RN fallback and test migration.
BrainyTalk native SwiftUI iPad: preserve stable vocabulary positions, SQLite data, speech, bilingual communication, parent mode, scanning, custom cards and backups. Real iPad and AAC professional/user review before launch. No required internet, ads, tracking or paywall for essential communication.
Spectrum Explorer remains React Native/Expo; preserve all features, location opt-out, favorites and offline operation. Versioned verified resource catalog, state-specific support, events and sensory filters. No SwiftUI conversion.
ReyOS remains Arch/KDE Plasma/Wayland with native Qt/QML apps and stable snapshot architecture. Website redesign first; native UI work is separate and must not degrade gaming, updates, recovery or RAM/CPU. Reyva and ReyBeat remain on existing stacks unless owner approves; no unrequested rewrite. BrainyRoutine future scope only.
