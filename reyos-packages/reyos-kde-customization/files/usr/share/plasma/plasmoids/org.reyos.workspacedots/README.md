# Desktop Indicator for Plasma
A simple applet that serves as a virtual desktop indicator. This is a fork of dhruv8sh's original desktop indicator project and is aimed at those who don't like  his new one, kara with support for Plasma versions>=6.6.

## Features:
* <b>NEW:</b> Set a vertical offset for active dot
* Support for Vertical Panels
* Support for custom spacing between indicators
* Contextual actions added
* 'Add Desktop' button added
* Customisable middle click action
* Switch desktops by scrolling widget
* Workspace wraparound
* Show desktops in a single row or follow Plasma setting
* Customisable indicator size, highlight size, spacing.
